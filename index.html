Pengaturan WebUSB & Printer Termal

Persyaratan Browser: WebUSB didukung langsung oleh Google Chrome, Microsoft Edge, dan Opera di Windows, macOS, Android, dan Linux.
Catatan untuk Pratinjau Tertanam: Akses perangkat langsung melalui WebUSB memerlukan tab terpisah. Klik untuk mengaktifkan koneksi WebUSB.

Langkah 1: Pengaturan Driver (Khusus Windows)

Windows biasanya menghubungkan printer termal ke driver cetak bawaan (`usbprint.sys`). Agar browser dapat mengakses USB langsung melalui WebUSB, ganti driver printer dengan WinUSB menggunakan Zadig:

  1. Unduh dan jalankan Zadig.
  2. Pilih Options -> List All Devices.
  3. Pilih printer termal Anda (mis. POS-58 atau POS-80 atau Xprinter).
  4. Atur Target Driver menjadi WinUSB (v6.1.7600.16385).
  5. Klik Replace Driver.

Langkah 2: Hubungkan Printer di Studio

  1. Klik tombol Hubungkan USB di kiri atas.
  2. Pilih printer Anda pada dialog USB Chrome.
  3. Jika berhasil terhubung, status di bagian atas akan berubah menjadi Terhubung.

Alternatif: Cetak Standar melalui CSS

Jika ingin memakai driver POS Windows/Mac yang sudah terpasang tanpa mengganti driver melalui Zadig, klik Cetak Standar (Alternatif via CSS) untuk membuka dialog cetak bawaan sistem.

Simpan Preset Profil Baru

Menyimpan ukuran kertas, dithering, ambang batas, kecerahan, kontras, rotasi, pangkasan, serta pengaturan baris tambahan dan pemotong di browser ini. Preset tetap tersedia setelah aplikasi ditutup dan dibuka kembali.
